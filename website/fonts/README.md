Self-hosted latin woff2 files for the kaf-mirror site.

- IBM Plex Sans (400, 500, 600, 700) and IBM Plex Mono (400) are
  subsetted from the official IBM/plex releases `@ibm/plex-sans@1.3.6`
  and `@ibm/plex-mono@2.5.0`. See LICENSE-IBM-Plex.txt (SIL Open Font
  License 1.1).
- Space Grotesk (600) is instantiated from the official variable font
  in floriankarsten/space-grotesk 2.0.0 and subsetted to latin. See
  OFL-Space-Grotesk.txt (SIL Open Font License 1.1).

The subsets cover the latin unicode range only. System fonts remain
the fallback for other scripts and for browsers that do not load
these files.
