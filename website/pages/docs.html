Docs, API and CLI.

The full documentation lives in the repository. This page is an index. The CLI reference is built into this site from the generated HTML in web/docu/cli-commands.html. The latest release is v2.0.0. There is also a comparison with MirrorMaker 2, Replicator and Cluster Linking.

What's new in 2.0.0

A short list of what landed in this release, with links to the docs. Read the GitHub release and the Breaking section of the changelog before you upgrade.

  • v2.0.0 release notes

    Highlights, breaking changes, security notes and upgrade steps. The image is ghcr.io/scalytics/kaf-mirror:v2.0.0. mirror-cli downloads include Linux arm64 and Apple Silicon.

  • Shell completion

    Bash, Zsh, Fish and PowerShell for mirror-cli and admin-cli.

  • Replication halt (tech preview)

    Off by default and admin-only. Freezes replication if the source looks compromised.
